### 작업 중 지켜야 할 것

- 원본(y=0) 프레임은 **읽기 전용**으로만 사용한다. 스타일·좌표·문구를 참조하기 위해 `get_metadata` / `get_design_context`로 읽는 건 자유롭지만, 어떤 수정·이동·삭제도 하지 않는다.
- 새 페이지를 추가하는 작업(작업 1의 `07-1. 경고 단계 실제 화면`)도 **복사본 줄에만** 추가한다. 원본 줄의 슬라이드 간격을 밀거나 x 좌표를 재배치하지 않는다.
- 페이지를 삭제하는 작업(작업 5의 옵션 A)도 복사본에서만 수행한다.
- 작업 완료 후, 어떤 프레임(id·이름·좌표)을 수정했는지 목록으로 보고할 것. 원본 id가 그 목록에 하나라도 들어 있으면 잘못된 것이다.

## 작업 0. 미아 프레임 `THRESHOLDS`를 07 페이지 제자리에 복원 (가장 먼저)

**대상**: `07. AI 피드백 전략 설계` 복사본 (node **`59:462`**)
**옮길 내용**: `THRESHOLDS` (원본 node `7:103`, 현재 `x=45196, y=27168`에 최상위로 떠 있음, 680×404)

**이 프레임의 정체 (확인 완료)**
캔버스 저 멀리 홀로 떠 있어서 정체불명이었는데, 대조 결과 **`07. AI 피드백 전략 설계` 페이지의 "② 확정 기준값" 섹션**이 맞다. 근거 세 가지:

1. **목차가 이걸 07번 내용으로 명시하고 있다.** `00-1. Contents` 페이지의 07번 항목 설명 텍스트(원본 `2:63` / 복사본 `59:50`)가 **"단계적 경고와 확정 기준값"**이다. 그런데 정작 07 페이지에는 "확정 기준값"이라는 블록이 없다 — 이 프레임이 빠져나갔기 때문.
2. **번호가 이어진다.** 07 페이지에 남아 있는 `FEEDBACK MAPPING`(복사본 `59:517`)은 원형 배지 번호가 **①**이고 제목이 "Feedback Mapping · AI 결과 → UI 피드백". `THRESHOLDS`는 배지 번호가 **②**이고 제목이 "확정 기준값". ①만 있고 ②가 없는 상태였던 것.
3. **크기가 빈자리에 정확히 들어맞는다.** 두 프레임 높이가 404로 동일하고, FEEDBACK MAPPING이 x=100~1100을 차지한 뒤 오른쪽이 통째로 비어 있다. THRESHOLDS 폭 680을 40 간격 띄워 넣으면 `1140 + 680 = 1820`으로 콘텐츠 우측 한계선(x=1820)에 딱 맞는다.

**해야 할 일**
1. `THRESHOLDS`(`7:103`)를 **복제**한다. (원본 자체를 이동시키지 말 것 — 원본 캔버스를 건드리지 않는다는 원칙 유지. 원본은 그 자리에 그대로 두고, 복제본만 사용.)
2. 복제본을 복사본 07 페이지(**`59:462`**)의 자식으로 넣고, **부모 기준 상대좌표 `x = 1140`, `y = 558`**에 배치한다. 크기 680×404 그대로 유지.
3. 배치 후 확인: FEEDBACK MAPPING(`59:517`, x=100 y=558)과 위쪽 끝이 나란히 맞고, 오른쪽 끝이 x=1820에서 끝나며, 두 프레임이 겹치지 않아야 한다.
4. 원본 `7:103`은 그대로 둔다. 정원의가 나중에 원본도 정리하겠다고 하면 그때 삭제.

**보고할 것**: 배치 후 07 복사본 페이지 스크린샷을 찍어 ①과 ②가 좌우로 나란히 보이는지 확인하고 결과를 알릴 것.

## 작업 1. 경고 4단계를 실제 화면 캡처로 보여주기

**대상**: `07. AI 피드백 전략 설계` (node `2:10`, 현재 12/18) — State Diagram과 FEEDBACK MAPPING 표가 있는 페이지.
관련 참고 페이지: `08-1. 실시간 감지 화면과 경고 단계` (node `2:12`, 현재 14/18) — 여기 "2 실제 화면 비교" 섹션(node `8:60` 실시간코칭, `8:64` 녹화·감지, `8:68` 분석 중, 각 260×563)이 이미 존재하지만 이건 앱의 **다른 화면 모드 3개**를 비교하는 섹션이지 경고 4단계 비교가 아님. 착각해서 여기 손대지 말 것.

**현재 상태**: `2:10` 페이지에 4단계(정상/주의/경고/강한경고) 정보가 텍스트로만 존재.
- State Diagram 행(node `7:23` "녹화·감지 중 4단계"): 4개 서브프레임 `7:25`(정상/기본색 유지) `7:28`(주의/5초~ 틴트) `7:31`(경고/10초~ 배너) `7:34`(강한경고/20초~ 경고음), 각 155×98, x=7/174/341/508 (부모 기준 상대좌표).
- FEEDBACK MAPPING 표(node `7:56`)에도 동일 4단계 + 정상복귀 + 분석중 + 세션리포트 행이 텍스트로 있음.
- 실제 스크린샷은 어디에도 없음.

**해야 할 일**:
1. `poise-deploy.vercel.app`를 브라우저로 열어 다음 4개 상태를 실제로 재현하고 캡처(390×844, 세로 모바일 뷰):

   - 경고(10초 경과): 상단 슬라이드다운 배너 노출 상태
   - 강한 경고(20초 경과): 강한 틴트 상태 (경고음은 캡처 불가하니 생략, 텍스트로 "경고음 1회" 표기)
   - 카메라가 없으면 시뮬레이션 스켈레톤 모드로 재현 가능 (2:14 "09.AI-UI연동구현" 페이지 체크리스트에 "카메라 권한이 없어도 시뮬레이션 스켈레톤으로 도는가" 항목이 이미 검증돼 있으므로 이 모드 사용 가능).
2. 새 페이지 `07-1. 경고 단계 실제 화면`을 `2:10`과 `2:11` 사이에 삽입 (기존 `03-1. 판정 기준 근거` 삽입 패턴과 동일하게: 1920×1080 프레임, 상단에 페이지 타이틀 바 — G.움직임기반... 좌측 로고텍스트(x=100,y=44) + 우측 프로젝트명(x=1120,y=46) + 좌측 세로바(x=100,y=86,w=6,h=84) + 타이틀(x=148,y=84) + 목표문구(x=150,y=150) + 우상단 OUTPUT 라벨 + 우하단 페이지번호. 이 구조는 모든 페이지에 동일하게 반복되니 인접 페이지(`2:10` 또는 `51:2`)의 헤더 요소를 그대로 복제해서 타이틀/목표문구/OUTPUT 라벨/페이지번호만 교체).

## 작업 4. 사용성 평가 및 개선 페이지 — 재구성

**대상**: `10. 사용성 평가 및 개선` (node `2:15`, 현재 17/18)

**현재 구조**: 4개 카드

**해야 할 일**:

3. 병합 후 남는 공간(카드1+3 통합, 카드2가 왼쪽 위 → 오른쪽 위 자리로 이동 가능)에 카드4(`9:213`, "개선안 도출")를 더 크게 확장. 카드4의 각 행(`9:219`~`9:241`: 문제→해결 매핑 4개)에 세 번째 컬럼 `앞으로 더 해결해야 할 점`을 추가:

   - "즉시 팝업으로 흐름 끊김 → 5/10/20초 단계적 경고" 옆에 → `향후: 사용자별 민감도 커스터마이징`
   - "거리·체형 판정 흔들림 → 어깨너비 정규화" 옆에 → `향후: 더 다양한 체형·거리 데이터로 검증`
