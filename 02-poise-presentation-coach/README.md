# 02 · Poise — 발표 습관 코칭

**움직임 기반 UX 분석 및 UI 디자인**

스마트폰·노트북 카메라로 발표 연습을 녹화하면, 자세에서 드러나는 습관 신호를 감지해 교정 리포트와 회차별 개선 추이를 보여주는 iOS 스타일 웹앱(PWA)입니다.

## 컨셉

발표를 "평가"하는 도구가 아니라 **혼자 연습하는 사람을 지지적으로 코칭**하는 도구입니다. 잘못을 지적하기보다 "다음엔 이렇게 해볼까요?" 톤으로 개선을 유도합니다.
범위는 움직임 신호로 한정했고, '발화 멈춤'은 음성 대신 전신 움직임이 일정 시간 멈추는 것으로 대신 감지합니다.

## 판정 기준과 근거

키포인트 좌표를 어깨너비로 정규화해 카메라 거리와 무관하게 판정합니다.

| 신호 | 기준 | 근거 |
|---|---|---|
| 시선 회피 | 코가 어깨 중심에서 어깨너비의 20% 이상 벗어남 | 눈맞춤 측정의 공통 기준이 없음을 밝힌 연구 (J. Nonverbal Behavior, 2020) → 단일 카메라 환경에 맞춰 직접 설정 |
| 고개 움직임 | 양 귀를 잇는 선의 기울기 11° 초과 | 5°도 신호로 쓰는 집중도 평가 연구 (2024) 범위 안 |
| 상체 흔들림 | 0.9초간 어깨중심 이동폭 / 어깨너비 > 0.16 | 체형 기준 정규화가 필요하다는 Kinect 흔들림 연구 (PLOS ONE, 2020) |
| 발화 멈춤 | 1.5초간 전신 움직임 / 어깨너비 < 0.05 | 발표불안 침묵 연구: 평균 정지 1.6초 ~ 9.8초 |
| 경고 단계 | 5초 틴트 → 10초 배너 → 20초 경고음 (습관별 8초 쿨다운) | 즉시 피드백이 발표를 방해했다는 Presentation Trainer 실사용 평가 (Sensors, 2019) |

신호가 겹치면 상체 > 고개 > 시선 > 발화멈춤 순으로 하나만 택하고, 0.5초 다수결로 떨림을 줄입니다. 세션 집계는 1.5초 구간에서 한 습관이 70% 이상일 때만 1회로 셉니다.

## 주요 기능

- **실시간 스켈레톤 오버레이:** 미러링 + object-fit 비율에 맞춘 좌표 매핑, 카메라가 없으면 시뮬레이션 모드
- **리포트:** SVG 도넛(습관 분포), 최다 습관 맞춤 코치 코멘트(받침에 따라 조사 자동 선택), 직전 회차 대비 증감
- **녹화 다시보기:** 영상 스크럽바 위에 감지 구간 마커를 표시하고, 마커를 누르면 해당 시점으로 이동
- **기록·통계:** 캘린더, 회차 리스트, 개선률, 회차별 바차트
- **저장:** 녹화 영상은 Supabase Storage, 세션 기록은 Postgres. 재접속하거나 다른 기기에서 열어도 유지 (14초 녹화 = 2.8MB webm 저장 확인)

### 실행

카메라는 HTTPS 또는 localhost에서만 허용됩니다.

```bash
cd prototype
python -m http.server 8080   # http://localhost:8080
```

Supabase를 쓰려면 `supabase-setup.sql`로 `sessions` 테이블과 `recordings` 버킷을 만들고 `js/app.js` 상단의 URL과 키를 바꿉니다.
