# 소리 내어 외우는 한국사 — 앱 프로토타입

기획안(`클로드코드_최종전달_기획스펙.md`)과 Figma UI 시안을 바탕으로 만든 **음성 기반 인터랙티브 암기 퀴즈** 프로토타입입니다.

> 핵심 UX: 사건(단어)이 잠깐 나타났다 사라지면 → 사용자가 **소리 내어** 답을 말하고 → STT가 텍스트로 변환 → **핵심어 포함 여부**로 정답을 판정.

## 구성

```
prototype/
├─ index.html   # 12개 화면 구조 (390×844 모바일 프레임)
├─ styles.css   # Figma 시안 디자인 시스템 재현
├─ app.js       # 상태 머신 · 타이머 · STT · 채점 · 팝업
├─ data.js      # 5문항 데이터(정답 키워드·해설·원문·통과기준)
└─ README.md
```

## 실행 방법

### 가장 쉬움 — `앱 실행.bat` 더블클릭
- 터미널·브라우저를 미리 켜둘 필요 없습니다. 더블클릭하면 자동으로 열립니다.
- **Python이 있으면**: 로컬 서버(포트 8123)를 켜고 브라우저를 자동으로 엽니다 → **마이크 사용 가능**.
  ('한국사암기 서버' 창은 사용 중 열어두고, 끝나면 닫으세요.)
- **Python이 없으면**: 자동으로 `index.html`을 파일 모드로 엽니다. 이 경우 마이크는 막힐 수 있으니
  듣기 화면의 `⌨️ 키보드로 답하기`로 전체 흐름을 그대로 볼 수 있습니다.

### 대안 — `index.html` 더블클릭
- Python·서버 없이 바로 열립니다. 마이크만 제한될 수 있고, 키보드 입력으로 전체 데모가 됩니다.

### 마이크까지 확실히 쓰려면 (권장 브라우저: Chrome / Edge)
Web Speech API·마이크는 **보안 컨텍스트(localhost / https)**에서만 안정적입니다. 직접 서버를 켜도 됩니다.
```bash
cd prototype
python -m http.server 8123
# 브라우저에서 http://localhost:8123 접속
```

- **음성으로 답하기**: 마이크 권한 허용 → 카드가 사라지면 소리 내어 답하기 → 2초 멈추면 자동 채점
- **키보드로 답하기(폴백)**: 미지원 브라우저(예: Firefox)나 마이크 불가 시 자동으로 입력창이 뜹니다.
  듣기 화면의 `⌨️ 키보드로 답하기`로 직접 전환할 수도 있어 **마이크 없이도 전체 플로우를 데모**할 수 있습니다.
- 마이크 버튼을 누르면 **말을 마치기 전에 즉시 채점**됩니다.

## 화면 플로우 (12 화면)

`스플래시 → 홈 → 단원 선택 → [카드 노출(3초) → 듣는 중 → 피드백] × 5 → 결과 요약`
+ 피드백 화면의 `해설 보기` / `원문 보기` 바텀시트 팝업.

## 채점 로직 — LLM이 아닌 하드코딩 키워드 매칭

기획 스펙의 **핵심 제약**대로, 채점에는 AI/LLM을 쓰지 않습니다.
`app.js`의 `grade()`가 STT 결과 텍스트에서 공백을 제거하고 `data.js`의 `정답_키워드` 포함 여부만 셉니다.

```
일치_개수 = 정답_키워드 중 인식 텍스트에 포함된 개수
if 일치_개수 == 전체:          완전 정답   (green)
elif 일치_개수 >= 통과_기준:   통과         (green)
elif 일치_개수 > 0:            부분 정답    (orange)
else:                          모름         (gray)
```

> **참고 — 부분정답 화면 보기**: 현재 `data.js`의 `통과_기준`은 스펙 JSON 그대로 **1**입니다.
> 키워드가 3개이고 통과_기준이 1이면 `1~2개 = 통과`, `0개 = 모름`이라 **부분정답(orange)**은 나오지 않습니다.
> 4가지 피드백 화면을 모두 보려면 `data.js`의 `통과_기준`을 **2**로 올리면 됩니다
> (그러면 `1개=부분정답`, `2개=통과`, `3개=완전정답`). 이 임계값 상향은 추가 지시 문서
> `클로드코드_추가지시_키워드추출.md`가 말한 "채점 기준 강화"와 같은 취지입니다.

## 학습 통계 화면 (실제 데이터 연동)

Figma 화면 13-a를 코드로 옮긴 **누적 학습 통계** 화면입니다. 진입 경로는 **홈 우상단 "📊 통계"** 버튼과 **결과 요약 화면의 "📊 전체 통계 보기"** 링크입니다.

데이터는 서버 없이 브라우저 **`localStorage`**(키: `korhist_stats_v1`)에 누적됩니다. 퀴즈를 1회 완료(결과 요약 도달)할 때마다 `recordSession()`이 아래를 기록합니다.

- **총 학습 횟수** — 완료한 세션 수
- **누적 정답률** — 전체 문항 중 (완전정답 + 통과) 비율
- **연속 학습일** — 세션이 있는 날짜의 연속 스트릭
- **정답률 추이** — 최근 7회 세션의 통과 문항 수(막대, 최신 회차 강조)
- **자주 놓치는 핵심어 Top3** — 매 문항에서 못 맞춘 정답 키워드를 누적 집계

> 처음 실행 시엔 기록이 없어 빈 상태로 보이고, 퀴즈를 풀수록 채워집니다. 기록을 초기화하려면 브라우저 콘솔에서 `localStorage.removeItem('korhist_stats_v1')` 후 새로고침하세요.

## STT 엔진에 대한 메모 (CLOVA Speech)

기획 스펙 §8은 최종 STT로 **네이버 CLOVA Speech(gRPC)**를 지정합니다. 다만:

- gRPC는 브라우저에서 직접 호출할 수 없어 **백엔드 프록시**가 필요하고,
- Secret Key는 아직 미전달이며 코드에 하드코딩 금지(`.env` 분리) 대상입니다.

그래서 이 **프로토타입 단계**에서는 별도 서버·키 없이 즉시 데모 가능한 **브라우저 Web Speech API(ko-KR)**를
STT 엔진으로 사용했습니다. STT는 "음성→텍스트" 변환일 뿐이고 **채점은 그대로 키워드 매칭**이라 스펙 제약과 충돌하지 않습니다.

실제 CLOVA로 교체할 때는 `app.js`의 STT 구간(`startSTT`/`onSpeechResult`)만 CLOVA gRPC 스트리밍 결과를
`onSpeechResult`와 동일한 형태(부분/최종 transcript)로 넘겨주면 나머지(타이머·채점·피드백)는 그대로 재사용됩니다.

## 조정 가능한 값

`app.js` 상단 `CONFIG`에서 시간값을 바꿀 수 있습니다.

| 값 | 기본 | 의미 |
|---|---|---|
| `CARD_MS` | 3000 | 카드 노출 시간 |
| `SPEECH_WAIT_MS` | 3000 | 이 시간 내 무발화 → '모름' |
| `SILENCE_MS` | 2000 | 발화 후 침묵 → 자동 채점 |

## (선택) CLOVA STT 연동

기본은 브라우저 Web Speech API입니다. **네이버 CLOVA STT**로 바꾸려면 `config.js`의
`clovaEndpoint`에 Supabase Edge Function URL을 넣으면 됩니다(비워두면 Web Speech 유지).

- 동작: 발화를 브라우저에서 16kHz WAV로 녹음 → Edge Function 전송 → CLOVA 변환 텍스트로 **동일한 키워드 채점**.
- 배포/키 설정 방법: 프로젝트의 `clova-backend/README.md` 참고. (CLOVA 키는 서버 시크릿에만 저장)
- 관련 파일: `config.js`(설정), `clova.js`(녹음·WAV 인코딩).
