# ■ p5 — 03. 정답 키워드 선정 및 근거 도출 (전면 재구성)

```
┌ 리드 박스 ──────────────────────────────────────────┐
├ ① 5단계 파이프라인 가로 띠 ─────────────────────────┤
├ ② 강화도 조약 추적 예시  │ ③ 슬롯 규칙 3장 + 재현 뱃지 ┤
├ ④ 문항별 최종 키워드 표 ────────────────────────────┤
├ ⑤ 알고리즘 / 사람 2단 대비 ─────────────────────────┤
└───────────────────────────────────────────────┘
```

**리드**
> **선정 기준 — 사람이 손으로 고르지 않고, 원문에서 알고리즘으로 계산해 뽑은 상위 키워드**
> 처음에는 키워드를 손으로 2~3개씩 골랐지만 주관적이라는 지적을 받았다. 형태소 분석 + TextRank 자동 추출로 바꾸고, 통과 기준도 1개 → 5개 중 3개로 함께 올렸다.

**① 파이프라인 띠** — 각 단계 [제목 / 방법 / 산출물] 3줄

| 1 원문 확보 | 2 명사 추출 | 3 중요도 계산 | 4 공통어 억제 | 5 슬롯 규칙 |
|---|---|---|---|---|
| 한능검 기출 5개 사건 | kiwipiepy 0.23 | TextRank · window 4 | ×IDF = log(N/df) | 연도 1 + 인물 1 + ×IDF |
| → 원문 5건 | → 후보 197개 | → 문항별 상위 5 | → 재가중 상위 5 | → 최종 5개 |

작은 글씨: `1~2단계 상세는 05장 · 4~5단계 검증은 06장`

**② 강화도 조약 추적 예시** (세로 4단)

| 단계 | 결과 |
|---|---|
| 명사 후보 39개 중 | 강화도 · 개항 · 개항장 · 군함 · 일본 · 일본인 · 조선 · 조약 · 치외 · 법권 · 허용 … |
| 순수 TextRank | 조선 .0898 · 조약 .0782 · 일본 .0522 · 일본인 .0382 · 허용 .0372 |
| ×IDF 재가중 | 조약 .0716 · 일본인 .0616 · 허용 .0599 · ~~조선 .0458~~ · 강화도 .0457 |
| 슬롯 규칙 → 최종 | **1876** · 조약 · 일본인 · 허용 · 강화도 |

'조선'에 취소선 + 회색 주석 `df ≥ 3 공통 일반어` / '1876'은 포인트 컬러 + 주석 `연도 슬롯 고정`

**③ 슬롯 규칙 3장** — 「핵심 1」 코드블록 내용을 카드 3장으로.
규칙 2 카드에 `→ 김옥균 · 전봉준 · 이토`, 규칙 3 카드에 `→ 강화도 조약에서 '조선' 빠짐` 예시 병기.

**재현 뱃지 (③ 하단, 포인트 컬러)**
> 규칙 3개만으로 5문항 최종 키워드가 **전부 그대로 재현된다.** 사람이 임의로 끼워 넣은 단어는 없다.

**④ 문항별 최종 키워드 표** — 열은 `문항 / 연도 / 최종 키워드 5개 / 통과 기준`. 값은 「핵심 2」 표 마지막 열 그대로.

**⑤ 알고리즘 / 사람 2단 대비**

| 알고리즘이 정한 것 | 사람이 정한 것 |
|---|---|
| 명사 후보 추출 · 중요도 점수 · 공통어 가중치 · 상위 5 순위 | 연도 1칸 고정 · 인물 1명 포함 · df≥3 제외 · 통과컷 3개 |

하단 한 줄
> **검토** — 1차 결과에서 '조선·일본'이 상위를 차지하는 것을 확인하고 IDF 재가중을 추가했다. 최종 5세트는 원문과 직접 대조해 검수했고 산출 근거를 `핵심키워드_추출근거표.xlsx`에 기록했다. LLM은 스크립트 작성 보조에만 사용했다.

**이동**: 지금 p5의 Input Mapping Table(2행)은 p6으로 옮긴다. p5는 키워드 산출 하나만 다룬다.

# ■ p8 — 06. AI 모델 학습 및 검증 (전면 재구성)

## 먼저 정리할 것 — 이 챕터의 성격

현재 목표 문구가 `AI 모델을 학습하고 성능을 확인한다. (C 트랙은 별도 학습 대신 …)` 로 되어 있다.
괄호로 얼버무리지 말고 **"학습을 안 한다"를 정면에 놓고, 왜 안 해도 되는지를 이 장의 논지로 삼는다.**
학습 데이터가 5문항뿐이라 지도학습이 성립하지 않고, 채점 근거를 설명해야 하는 서비스라 규칙 기반이 오히려 맞다.

**새 목표 문구**
> 목표: 학습형 모델 대신 규칙 기반 추출·채점을 택한 이유를 밝히고, 그 결과가 의도대로 동작하는지 검증한다.

### 레이아웃

```
┌ 리드 박스 — 학습을 안 한 이유 ──────────────────────────┐
├ ① 학습형 vs 규칙형 2단 대비 ─────────────────────────┤
├ ② 전후 비교 (5문항) ──────┬ ③ 검증 설계 · 20케이스 ───┤
├ ④ 발견한 결함 2건 → 추가 규칙 ──────────────────────┤
├ ⑤ 마무리 한 줄 ────────────────────────────────┤
└──────────────────────────────────────────┘
```

---

**리드 박스**
> **학습시킬 데이터가 없어서가 아니라, 채점 근거를 설명해야 해서 규칙을 택했다**
> 문항이 5개뿐이라 지도학습에 필요한 라벨 데이터가 성립하지 않는다. 그리고 사용자에게 "왜 통과인지"를 키워드 단위로 보여줘야 하는 앱이라, 점수만 내놓는 모델보다 규칙이 맞았다.

---

**① 학습형 vs 규칙형 2단 대비**

| | 학습형 모델 | **규칙 기반 (이 프로젝트)** |
|---|---|---|
| 필요한 것 | 라벨링된 학습 데이터 수천 건 | 문항별 원문 + 추출 규칙 |
| 판정 근거 | 설명 어려움 (점수만 나옴) | 맞은 키워드·빠진 키워드를 그대로 제시 |
| 재현성 | 같은 답변에 다른 결과 가능 | 같은 답변은 언제나 같은 결과 |
| 이 프로젝트 상황 | 5문항으로는 성립 불가 | 5문항이라 오히려 전수 검증 가능 |

박스 아래 한 줄
> AI는 음성 → 텍스트 변환(CLOVA STT)에만 쓰고, 맞고 틀림은 규칙이 정한다. TextRank는 페이지랭크와 같은 그래프 알고리즘으로, 학습하지 않는다.

---

**② 순수 TextRank vs ×IDF 전후 비교 — 5문항 전부** (지금 3문항만 있음)

값은 「핵심 2」 표의 5·6열 그대로. 새로 올라온 단어만 볼드.

| 임오군란 | 군인 · 청나라 · 군대 · 개화 · 구식 | 군인 · 개화 · 구식 · **정책** · **임오군란** |
| 갑신정변 | 정변 · 개혁 · 급진 · 청국 · 개화파 | 정변 · 청국 · 개화파 · **김옥균** · 개혁 |
| 동학농민운동 | 운동 · 농민 · 농민군 · 전투 · 동학 | 운동 · 농민 · 농민군 · 전투 · 동학 |

- **② 최종 키워드 구성 규칙 4행 표는 p8에서 삭제** — p5 「슬롯 규칙 3장」과 완전 중복.

| 심각도 | 발견 | 원인 | 추가 규칙 |
|---|---|---|---|
| 높음 | 통과컷을 3으로 올린 뒤에도 강화도 조약·동학농민운동은 사건명+연도만으로 통과 | 사건명을 이루는 단어(조약·강화도 / 운동·농민)가 키워드 슬롯에 그대로 들어감 | 키워드에 `연도 / 사건명 구성어 / 내용어` 태그를 붙이고, **통과 이상은 내용 키워드 1개 이상 필수** |
| 높음 | "농민군" 한 단어로 `농민`·`농민군`이 동시 카운트 | 부분 문자열 포함으로만 세고 있음 | 긴 키워드 우선 매칭 후 매칭 구간 소비 |

적용 후 판정 규칙
```
matched == 5                              → 완전정답
matched >= 3  AND  content_matched >= 1   → 통과
matched >= 1                              → 부분정답
matched == 0                              → 모름
```

적용 결과: 강화도 조약·동학농민운동 두 문항 모두 **부분정답으로 정정**된다.

> **이 결함을 찾아 규칙을 추가한 순서 자체가 직접 검토했다는 증거다. 숨기지 말고 그대로 노출할 것.**
